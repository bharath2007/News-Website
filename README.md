# News Website

## Overview

News Website is a simple web application developed using HTML and CSS that presents news articles in a clean and organized format. The website contains multiple categories including Technology, Sports, and Business.

The project demonstrates basic web development skills and website deployment using GitHub Pages.

## Features

* Responsive homepage
* News categorization
* Modern user interface
* Easy navigation
* Mobile-friendly design
* Live deployment using GitHub Pages

## Technologies Used

* HTML5
* CSS3
* GitHub
* GitHub Pages

## Categories

* Technology News
* Sports News
* Business News

## Objectives

* Develop a news portal using web technologies.
* Organize content into categories.
* Learn website deployment.
* Create a user-friendly interface.

## Future Enhancements

* Dynamic news updates
* News API integration
* User authentication
* Search functionality
